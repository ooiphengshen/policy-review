# Client Policy Review

A single-page app for keying in a client's in-force policies and benefits. It produces a policy review with coverage totals, a PDF, an Excel file and a WhatsApp summary.

**Open the app:** https://ooiphengshen.github.io/policy-review/

- Works in any browser on phone, tablet or computer.
- Client details you key in are saved only in your own browser (localStorage). Nothing is sent to a server.
- Use **Backup all** / **Restore backup** to move clients between devices.

The example client ("Load example") is fictional.
